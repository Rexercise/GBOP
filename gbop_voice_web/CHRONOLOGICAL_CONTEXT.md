# Chronological range review

`shift_review.review_shift` separates navigation from qualification. Full ordered
opposing-liquidity delivery or an outside H1 close advances review on that
candle's closure. The next candle becomes a **range under review**, not an
automatically confirmed CRT or named play. The internal `selected_range` role
is retained for compatible routing; `selection_status` explains its meaning.
Fifty-percent delivery alone does not advance review. Missing hours block a
verified handoff.

`chronological_context` is a bounded graph of the retained hourly ranges and
their original/double-purge phases. Source return and H1 return are separate
facts. Source return alone cannot create a confirmed-return context. This does
not change the existing named 9ate8 eligibility gate.

Contexts have explicit establishment, evidence-through and retirement times.
Full delivery and range invalidation retire them; a still-unreached full target
remains active after midpoint delivery. Later gaps or boundary-bar uncertainty
do not erase earlier fully covered relationships. A native H1-confirmed double
purge uses its own post-confirmation source prefix, not the original phase's
possibly incomplete earlier prefix. Simultaneous establishments do not receive
invented precedence.

Comparisons count distinct ranges, never separate closure/Soup confirmations
from one range. Countertrend relationships identify the earlier intact ranges
at the later event time. They do not imply majority voting, improved probability
or permission to trade. A two-sided, context-dependent Young Lefty remains
unselected and is excluded from directional counts.

Pending original and confirmed double-purge phases use separately labeled
primary body Model 1 identities. Each keeps its own CRT invalidation and strict
CISD distinct from parent validity. Later re-purges cannot replace the primary;
a missing reversal body cannot inherit the original direction's body. An
identity beyond a capped lifecycle page is present with unverified omitted
lifecycle detail, rather than falsely absent.

The raw story retains the complete bounded graph. The default synopsis keeps
all active contexts and countertrend relationships; its omitted aligned-history
count is explicit. Exact range evidence stays available through existing detail
requests. Spoken boundaries identify the end of the GTOP day/night shift and
name closures by candle opening, including non-H1 variant explanations.

Dense voice summaries keep the existing 12,000-character cap. Lossless fallback
encoding shares range defaults and uses declared columns for source intervals
and targets; exact timestamps, scopes and values are retained. In-payload
`same_evidence_as` references can additionally share identical facts. Tests
expand these forms and require exact round trips. Prepared-evidence versioning
prevents earlier under-review semantics from surviving a saved preparation.
