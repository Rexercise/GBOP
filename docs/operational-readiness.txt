Implemented in this candidate:

  logging state transitions without repeated external messages. Over 120-second
  capture = delayed; over 300 seconds/missing = collector attention. Fresh upload

  No DM, webhook, automation, new credential or new persistent process is added.
- Optional reported evidence_notes and decision_notes in the existing durable
  story. Compact review includes asset, play, evidence, decision, outcome and
  unknown R. Prompt requests review before finalization; this is guidance to the
  conversational model, not proof that a spoken readback occurred. Live acceptance
  must confirm the behavior and actual returned save receipt.
- Read-only review_journal_against_plan selects the authenticated member's Trade #
  and exact dated day/night plan. It asks only for missing date/shift, rejects
  conflicting scope, preserves unknowns, and never grades from P/L. Plans are
  currently saved versions; original pre-trade plan version is NOT established.
  The tool is included in the existing safe read-only interruption recovery list.
